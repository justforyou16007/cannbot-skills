# R-2201-001 归档：UB 常驻复用

## 结论从哪来

探针判定，job 7：`mte2_pct` 61.2 → 31.0，总时间 −24.3%。通道是
`signature_probe.py` 的 pipeline 段（源 CSV 是 `PipeUtilization.csv`）。

## 参考侧细节

无。这条结论不是从任何参考实现反推出来的 —— 它来自两份公开文档
（`ub_resident_design.md`、`npu-hardware-params.md`）加一次自家探针实测。

这一句本身就是归档要记的东西：**空文件和「没有参考侧细节」是两件事**。
前者让人不知道是没写还是没有，后者是一个可复核的陈述。

## 换一个参考时哪部分会变

都不会变。机制（省搬运次数而非计算量）、反指征（compute_bound 时无效、
UB 余量不足时净负）、与 double buffer 争 UB 这三条都是 DAV_2201 的硬件
性质，与是谁实现的这个算子无关。

会变的是收益幅度：−24.3% 是那一次的形状（复用次数 N 与常驻块大小）下的
数，换形状要重测。卡片正文里因此没有写这个数，只写了「N 越大收益越大」。
